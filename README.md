## 📌 Project Overview
This project provides a comprehensive analysis of telecom subscriber data, focusing on the identification of churn drivers and customer behavior patterns. Built using **Power BI**, the dashboard provides stakeholders with the tools needed to visualize risk segments and improve retention performance.

## 🛠️ Tech Stack & Architecture
* **BI Tool:** Power BI (Desktop & Service).
* **Languages:** DAX, SQL.
* **Data Modeling:** Star Schema Design.
* **Deployment:** RLS, Data Gateways, Workspace Management.

## 🚀 Key Deliverables
* **Production-Level Reporting:** Published 3+ production-level dashboards with configured gateways and automated scheduling.
* **Advanced DAX:** Implemented complex DAX measures (Aggregate, Date, Logical, and Table functions) for custom KPI tracking.
* **Data Security:** Enforced RLS to restrict sensitive subscriber data visibility based on user roles.
* **Optimization:** Executed performance tuning techniques including pushdown logic and data loading optimizations to reduce report latency.
